# Roadmap

## v0.3.0
- Click-to-place text and images on an interactive page canvas
- Page thumbnail sidebar with drag-and-drop reordering
- Highlight, freehand drawing, shapes, and sticky-note annotations
- True redaction with content removal
- PDF form filling and flattening
- OCR for scanned PDFs using Tesseract

## Later
- Digital certificate signatures
- Compare two PDFs
- Batch processing
- Optional FastAPI multi-user deployment
- Azure Blob/S3 temporary storage with retention controls
