# v0.5 Design Notes

This release uses PdfCraft as product inspiration, not as copied code. The implementation remains PeaBox's Python/FastAPI/PyMuPDF application.

Adopted principles:
- the PDF page is the primary workspace
- compact icon rail rather than a large upload panel
- persistent page thumbnail navigation
- focused central canvas with dark surround
- contextual inspector rather than permanent forms
- private/local-first processing
- organize and combine workflows alongside editing
- clear distinction between reading, selecting existing text, and adding objects
