# Changelog
## v1.0.0 Desktop
- Replaced the web application with a native PySide6 desktop application
- Added labeled tools, page thumbnails, native scrollbars, Fit Page, and 100% view
- Added strict rectangle-preserving existing-text replacement
- Long replacements are rejected rather than altering document structure
- Added Save As, reload original, image/signature insertion, rotate, delete, and merge
- Added unsaved-change protection and engine tests
